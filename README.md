# Turn-Based-Tactical-Card-Game
Mục tiêu:  Thiết kế và xây dựng một game chiến thuật theo lượt (turn-based) 2D bằng C++ và thư viện Raylib.  Phát triển và thử nghiệm các cơ chế gameplay/combat mới lạ.  Xây dựng kiến trúc mã nguồn sạch áp dụng Lập trình hướng đối tượng (OOP) và các Cấu trúc dữ liệu tối ưu (Vector, Linked List, Queue, Binary Tree,...).
